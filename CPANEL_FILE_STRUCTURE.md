# 📦 cPanel Production File Structure Guide

## Complete Directory Layout for cPanel

After deployment to cPanel, your public_html directory should look like this:

```
/home/username/public_html/
│
├── 📄 CONFIGURATION FILES (Top Level)
│   ├── .env.local                 ⭐ CRITICAL - Environment variables (NOT in git)
│   ├── .env.example               📋 Template for environment variables
│   ├── .htaccess                  🔒 Apache rewrite & security rules
│   ├── .cpanel.yml                ⚙️ cPanel deployment automation
│   ├── .gitignore                 📝 Git ignore rules
│   ├── package.json               📦 Dependencies list
│   ├── package-lock.json          🔒 Locked dependency versions
│   ├── tsconfig.json              🔧 TypeScript configuration
│   ├── next.config.ts             ⚡ Next.js configuration
│   ├── tailwind.config.ts         🎨 Tailwind CSS configuration
│   ├── postcss.config.mjs          🎯 PostCSS configuration
│   └── eslint.config.mjs           📐 ESLint configuration
│
├── 📁 APPLICATION CODE (app/)
│   ├── api/
│   │   └── send-booking/
│   │       └── route.ts           📨 WhatsApp API endpoint
│   ├── layout.tsx                 📐 Root layout & metadata
│   ├── page.tsx                   🏠 Main application
│   ├── globals.css                🎨 Global styles
│   └── favicon.ico                🔑 Favicon
│
├── 📁 STATIC ASSETS (public/)
│   ├── logo.png                   🌿 Your Berakhah logo
│   ├── next.svg
│   ├── vercel.svg
│   └── ...other assets
│
├── 📁 BUILD OUTPUT (.next/) 
│   ├── static/                    Generated static files
│   ├── server/                    Server runtime
│   ├── cache/                     Build cache
│   └── ...
│   
├── 📁 DEPENDENCIES (node_modules/)  ~500MB (installed via npm)
│   └── All npm packages here
│
├── 🚀 SERVER ENTRY POINT
│   └── server.js                  Node.js server for cPanel
│
└── 📚 DOCUMENTATION (Root Level)
    ├── README.md                  Main project readme
    ├── CPANEL_DEPLOYMENT.md       Complete deployment guide
    ├── DEPLOY_QUICK_START.md      5-minute quick start
    ├── PRODUCTION_CHECKLIST.md    Pre-deployment checklist
    ├── WHATSAPP_SETUP.md         WhatsApp API setup
    ├── AGENTS.md                  AI agents config (if used)
    └── CLAUDE.md                  Related to AGENTS.md
```

## File Purposes

### 🔐 Critical Files (Must Exist & Be Correct)

| File | Purpose | Example |
|------|---------|---------|
| `.env.local` | Environment variables | `WHATSAPP_PHONE_NUMBER_ID=xxxxx` |
| `server.js` | Production Node.js entry point | Starts the app on port |
| `package.json` | Dependencies & scripts | Lists all npm packages |
| `.next/` | Compiled app (generated by build) | Output of `npm run build` |

### ⚙️ Configuration Files

| File | Purpose |
|------|---------|
| `next.config.ts` | Next.js settings (images, rewrites, etc) |
| `tsconfig.json` | TypeScript compiler options |
| `tailwind.config.ts` | Tailwind CSS theme & plugins |
| `postcss.config.mjs` | CSS processing config |
| `.htaccess` | Apache rewrite rules & caching |
| `.cpanel.yml` | Automated deployment config |

### 📁 Important Directories

| Directory | Contents | Size | Deletable? |
|-----------|----------|------|-----------|
| `app/` | Application code | ~200KB | ❌ No |
| `public/` | Static assets | ~500KB | ❌ No |
| `.next/` | Build output | ~50-100MB | ✅ Yes (rebuild with `npm run build`) |
| `node_modules/` | Dependencies | ~500-700MB | ✅ Yes (reinstall with `npm install`) |

## Pre-Deployment Checklist

### Files That MUST Exist

- [ ] `server.js` - Production entry point
- [ ] `.env.example` - Template (for reference)
- [ ] `.htaccess` - Apache configuration
- [ ] `package.json` - Dependencies list
- [ ] `app/page.tsx` - Main app
- [ ] `public/logo.png` - Your logo
- [ ] All documentation files (*.md)

### Files That MUST NOT Exist

- [ ] `.env` - Never commit
- [ ] `.env.local` - Never commit (create on server)
- [ ] `.next.backup*` - Remove before upload
- [ ] `node_modules/` - Never commit (too large)
- [ ] `.env.production` - Use .env.local instead

### Files to Create on Server

- [ ] `.env.local` - Copy from `.env.example` and add credentials
- [ ] Logs directory (created automatically)

## Directory Permissions

Proper permissions for cPanel security:

```bash
# Directories: Read, Write, Execute for owner
chmod 755 ~/public_html              # Main directory
chmod 755 ~/public_html/app
chmod 755 ~/public_html/public
chmod 755 ~/public_html/.next

# Files: Read, Write for owner only (sensitive)
chmod 600 ~/public_html/.env.local   # Environment variables
chmod 600 ~/public_html/server.js
chmod 644 ~/public_html/*.json       # Configuration files
chmod 644 ~/public_html/*.ts         # TypeScript files
chmod 644 ~/public_html/.htaccess    # Apache config
```

## Upload Strategy

### Option 1: Git Clone (Recommended for updates)
```bash
cd ~/public_html
git clone https://github.com/yourusername/berakhah-gardens.git .
```

### Option 2: Upload ZIP via cPanel File Manager
1. Create ZIP excluding node_modules, .next, .env.local
2. Upload to cPanel File Manager
3. Extract in public_html

### Option 3: FTP Upload
```bash
# Connect via FTP
ftp your-domain.com

# Upload all files except:
# - node_modules/
# - .next/
# - .env.local
```

## Production vs Development

### Development (Local)
```
├── .env             (local, not committed)
├── .next/           (development build)
├── node_modules/    (local packages)
└── package-lock.json
```

### Production (cPanel)
```
├── .env.local       (created from .env.example)
├── .next/           (production build from `npm run build`)
├── node_modules/    (from `npm install --production`)
└── package-lock.json
```

## Performance Optimization

### Reduce Disk Usage:
```bash
# Clear npm cache
npm cache clean --force

# Remove .next backup files
rm -rf ~/public_html/.next.backup*

# Remove old logs (keep 7 days)
find ~/public_html/logs -mtime +7 -delete
```

### Improve Build Speed:
```bash
# Use production build cache
NODE_ENV=production npm run build

# Install only production dependencies
npm install --production --no-audit
```

## Troubleshooting

### "Disk space full" Error
```bash
# Check what's using space
du -sh ~/public_html/* | sort -rh | head -10

# Likely culprits:
# - node_modules/ - Delete and reinstall
# - .next/ - Delete and rebuild
# - logs/ - Archive old logs
# - backups/ - Move to backup location
```

### "File not found" Error
- Verify file was uploaded correctly
- Check file permissions: `ls -la ~/public_html`
- Verify path is correct (case-sensitive on Linux)

### "npm: command not found"
- SSH into cPanel
- Use full path: `/usr/local/bin/npm`
- Or contact hosting provider

## Security Notes

### Never Upload to Git:
- `.env.local` - Contains API keys
- `node_modules/` - Can be regenerated
- `.next/` - Can be regenerated
- Logs with sensitive data

### Always Verify:
- File ownership: `ls -l ~/public_html`
- Permission correctness before going live
- `.env.local` permissions are 600 (readable only by owner)
- SSH key security if using Git
